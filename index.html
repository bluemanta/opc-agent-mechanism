Bluemanta OPC

Linear Issue 直读式多桌面 Agent 工作流 MVP

核心原则
    01

    协作架构

    Linear Issue 是任务本体；桌面 Agent 直接读取 Issue，并结合自身项目上下文执行。

    02

    上下文分层

    项目层放长期事实，Issue 层写任务差量，评论层留执行证据。

    03

    任务状态流转

    Agent 交付进入 In Review，Done 才是闭环。

    流转规则

      04

      Linear 标签体系

      每个 Issue 用角色、员工和任务类型三类标签完成路由；阻塞统一使用 Blocked。

      05

      Linear Issue 模板

      Issue 是任务本体，需要写清目标、范围、验收和回填要求。

      Executor override

      06

      搭建执行顺序

      先搭账本，再放项目背景，然后用真实 Issue 跑一周试点。

      试点检查清单

        07

        可复制工作模板

        把这些 Markdown 直接复制到 Linear Project、Linear Issue 或 Issue 评论里使用。

        08

        桌面 Agent

        这些不是后台机器人，而是已经绑定项目上下文、可直接读取 Linear Issue 的桌面执行工具。

        09

        每日运行节奏

        先自动整理任务，再由你选择桌面 Agent 执行。

        自动化路径
